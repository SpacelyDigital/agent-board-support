Support

Agent Board reads local chat activity from the folders you select. It has no support upload, account registration or log-reporting service.

For help, email Spacelydigital@gmail.com. The link opens your mail app. Agent Board does not send a message or attach chats, logs or other data automatically.

My chats do not appear.

Open Agent Board → Setup and Permissions and select the source folders for the coding tools you use. An unselected or unavailable folder stays disconnected. Cloud-only chats are not included in the Store build.

A chat is checking history or has no confirmed status.

Agent Board verifies local session records before confirming that work has finished. A large, incomplete or changing file may take longer. Leave the board open, then check the source app if its status remains uncertain. Agent Board does not assume a quiet chat is finished.

I see an old usage reading or no usage figure.

Usage is a local observation, not a live account connection. Codex must have reported a weekly window in its local session records. Claude requires the optional local usage plugin and a compatible version. A normal response in the provider app may update the reading. Agent Board never sends a prompt to refresh it or assumes that a passed reset means a new full allowance.

If you switch accounts, clear old exports before relying on a reading. The Claude plugin's local files are agent-board/usage/quota-v1-a.json and quota-v1-b.json below the Claude folder you selected.

Notifications are not appearing.

Enable notifications in Agent Board and allow them in macOS System Settings under Notifications. Check Focus settings too. Monitoring still works when notifications are off or denied.

The chat link does not open the right place.

Open the coding tool directly and confirm the chat is still available. Exact-chat links depend on the provider app and its version. A reviewed or snoozed card changes only your board; it does not archive the original chat.

I want to stop monitoring or remove local data.

Forget the source folders in Setup and Permissions to stop reading them. Quit Agent Board to stop its collector. To remove the board's database and logs, first choose Open Local Data Folder, then quit the app and remove that folder. Your provider chats stay separate. Appearance settings and notification preferences are separate local stores.

If you installed the optional Claude exporter, disable or uninstall it in Claude and remove its two output files to clear its saved observations.

If Agent Board is useful to you, you can support its development on Ko-fi. Contributions are optional and do not unlock app features.

Agent Board does not need your chats, passwords or diagnostic files for these steps.
